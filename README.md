# SportsZone Bot 🏆

A Telegram bot for sports trivia, facts, and interactive quizzes.

## Features
- Daily sports trivia questions
- Fun sports facts
- Interactive 5-question quizzes
- Match highlights
- Player statistics
- Multiple sports categories

## Commands
- `/start` - Welcome & main menu
- `/help` - Show all commands
- `/trivia` - Get random trivia
- `/fact` - Fun sports fact
- `/quiz` - Start a quiz
- `/highlight` - Match highlights
- `/stats` - Player stats
- `/sports` - Sports categories
- `/daily` - Daily featured content
- `/about` - About this bot

## Deployment
1. Set `BOT_TOKEN` as environment variable
2. Deploy on Railway
3. Bot will auto-start
